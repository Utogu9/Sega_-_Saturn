# Sega Saturn

Artwork and metadata for [OpenCabinet-BDD](https://github.com/Utogu9/OpenCabinet-BDD).

- Base artwork: [libretro-thumbnails](https://github.com/libretro-thumbnails/libretro-thumbnails) and its contributors.
- Game names and identifiers: [Redump](https://redump.info/).
- Shared metadata: [Wikidata](https://www.wikidata.org/) contributors ([CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)).
- Additional scans and manuals: [Sega Retro](https://segaretro.org/) and the contributors identified in each asset's `sources` records. The recorded uploader is not necessarily the artwork's author.
- Additional Sonic covers and disc scans: [Sonic Retro](https://info.sonicretro.org/) and the uploaders credited in each image's `sources` records.

Sources and available contributor credits are retained in `catalog.json` and, where present, `console_artwork.json`. Artwork belongs to its respective rights holders; this repository does not assign it a new license.
